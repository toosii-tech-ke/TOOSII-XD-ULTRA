# Toosii-XD-Ultra 🚀

A WhatsApp bot launcher. `node launcher.js` fetches the latest runtime from the
Toosii Tech distribution API, keeps your session/settings across updates, and
starts the bot — so every deployment is always current.

## Deploy

1. Upload this repo as a ZIP to your panel (Katabump, Render, etc.)
2. Copy `.env.example` to `.env` and fill in `OWNER_NUMBER` (+ `SESSION_ID`, or pair via console code)
3. `npm run deploy`
4. Scan the pairing code with your phone

## Commands

484 commands across 15 categories — run `.menu` inside WhatsApp.
